# Recruiter reading path

## 60-second path

1. Read the [README hero](../../README.md) for the user problem and current
   product.
2. View the desktop and mobile screenshots in the
   [screenshot manifest](./SCREENSHOT_MANIFEST.md).
3. Read the [generated status](../../PROJECT_STATUS.md) to see what is current,
   blocked, and not started.

Expected takeaway: this is a human-centered sensory-language product backed by
a governed PostgreSQL research system, not a scraping archive or unvalidated AI
claim.

## 3-minute path

1. Read [PORTFOLIO.md](../../PORTFOLIO.md).
2. Skim “Iteration and correction” in the [case study](./CASE_STUDY.md).
3. Inspect the evidence architecture diagram in the root README.
4. Review the Round 3J/3L negative finding and Round 3M correction.
5. Read the [ML readiness ladder](../ml/BASELINE_TO_DEEP_MODEL_LADDER.md).

Expected takeaway: the project can invalidate its own scale assumptions, revise
the schema and gate, and explain precisely what a future model would require.
