## 触发概率（穷举）

方法：题库全部答案组合 Q0×Q1×Q2×Q3×Q4×Q5 = 4×4×4×4×3×4 = 3,072 条序列，在 6 种语境下各跑一遍（共 18,432 条），每条序列用三种勾选方式判断 Q6 是否开启。

| 语境                        | 序列数 | 按候选顺序勾前 5 个 | 随机勾 5 个 | 勾选偏向自己感受的 5 个 |

| 浅烘 · 手冲 · 日晒 · 瑰夏   |  3,072 |               24.1% |       18.9% |                   55.9% |
| 中浅烘 · 手冲 · 水洗 · 波本 |  3,072 |               30.4% |       19.9% |                   59.2% |
| 中烘 · 法压壶               |  3,072 |               36.1% |       21.6% |                   64.9% |
| 中深烘 · 意式萃取 · 日晒    |  3,072 |               37.1% |       20.2% |                   65.5% |
| 深烘 · 意式萃取             |  3,072 |               51.0% |       20.4% |                   76.3% |
| 合计                        | 18,432 |               34.2% |       20.1% |                   63.3% |

按路径（合计 18,432 条）：

| 路径                         | 序列数 |  占比 | 前 5 个 | 随机 5 个 | 偏向自己的 5 个 |
| ---------------------------- | -----: | ----: | ------: | --------: | --------------: |
| Path 1（答案与初始参考一致） |  2,304 | 12.5% |      0% |        0% |              0% |
| Path 2                       | 13,536 | 73.4% |     36% |       22% |             70% |
| Path 3                       |  1,800 |  9.8% |     65% |       33% |             96% |
| Path 4                       |    792 |  4.3% |     32% |       24% |             67% |

要点：

- Path 1 永远不开 Q6，这是设计：答案与初始参考一致，没有需要再确认的分歧。
- Q6 的开关同时看两件事：问答走了分歧路径（Path 2/3/4），以及勾选的 5 个词偏向读者自己的答案而不是初始参考。所以勾选决定成败：即使是最容易触发的序列，8 个候选词的 56 种 5 词组合里也只有约一半会开 Q6。下面每条序列都给出了应勾选的 5 个词。
- 回归测试固定的下限：Path 1 为 0；前 5 个 ≥ 20%；偏向自己的 5 个 ≥ 45%；Path 2/3/4 各 ≥ 25%。

## 前台测试序列

每条都在 session API 里验证过会开启 Q6；第 1 条和第 6 条另外在浏览器预览里走通（Q6 弹层出现、勾选、点「更新风味卡」、风味卡显示「已确认」）。

产地卡可跳过，除非序列里写了产地。Q6 弹层里任选 1–3 个描述，点「更新风味卡」。
