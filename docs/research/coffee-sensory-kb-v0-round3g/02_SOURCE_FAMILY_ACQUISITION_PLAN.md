# Source-family acquisition plan

## Frozen search order

Acquisition began only after the expected-state commit. The bounded plan was:

1. inspect named coffee sensory papers or repository records relevant to the
   seven current ranges;
2. inspect one named contemporary bilingual or lexical source for the six
   declared high-risk wording groups;
3. revisit the two existing data-on-request records without sending messages;
4. stop each candidate at an explicit admission, rights, privacy, access or
   scope decision; and
5. stop the round once all seven ranges and all inherited relationships had a
   review, rather than continuing an open-ended search.

Searches actively sought separation and incompatibility, not just support:
separate source variables, method differences, preparation dependence,
language/register differences, missing target terms, and license barriers were
all retained.

## Admission rules

One paper, its supplement, repository workbook and project derivative count as
one family. Mirrors and multiple files never create independence. Admission
requires an exact version, stable locator, rights decision, privacy decision,
verified SHA-256 and public-export decision. Incompatible sources remain
separate; no cross-source pooling was performed.

## Stop result

Six named candidates were sufficient to complete the declared plan. Two
families were admitted, two were rejected for reuse rights, one for access
terms, and one as out of scope. The machine register is
`db/data/round3g/source_candidate_register.tsv`.
