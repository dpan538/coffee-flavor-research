# Association measurement methods

Round 3G imports source summary values but computes no co-occurrence, Jaccard,
conditional co-occurrence, PMI/PPMI, co-selection or combined association
score. RATA means remain source variables, not membership weights or sensory
similarity.

The frozen controls remain:

- minimum expression occurrence: 3;
- minimum document or source-defined sample records: 2;
- source diversity: 1 independent family for source-local support, 2 for
  cross-source support;
- long-tail disposition: `INSUFFICIENT_FOR_RANGE`; and
- stability: exact configuration and counts must reproduce, with no pooling
  across incompatible semantics, panels, languages, preparations, roasts,
  samples, scales, units or protocols.

The promoted smoke claim uses nine source-defined sample configurations and
one family. Lexical title attestations have only 0–2 support records and remain
insufficient. No value is interpreted as a sensory-neighbour claim.
