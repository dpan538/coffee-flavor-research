# Range lifecycle decisions

All seven ranges were reviewed and all remain `CANDIDATE`.

| Range                   | Decision                                                                                        |
| ----------------------- | ----------------------------------------------------------------------------------------------- |
| floral / tea            | retain; no source-defined grouping or bilingual review                                          |
| fruit                   | retain; Jackfruit Aroma is relevant but does not validate the full range                        |
| cocoa / nut / caramel   | retain; no admitted source tests the combined range                                             |
| roast / spice / smoke   | retain; one smoke membership is supported, while smoky and roasty are separate source variables |
| sweet-associated        | retain; direct Sweet ratings do not establish caramel/honey association                         |
| acidity character       | retain; Sour is separate and bright/citrus/juicy compatibility is unresolved                    |
| texture / body / drying | retain; Body and Astringent Aftertaste are separate and current members are not validated       |

No range becomes `SOURCE_LOCAL_SUPPORTED`, `CROSS_SOURCE_SUPPORTED`,
`BILINGUAL_REVIEWED`, `RESEARCH_REVIEWED` or `ACTIVE_FOR_CALIBRATION`.
