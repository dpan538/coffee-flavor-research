# Next model implications

The current C0/C1 schema is ready to constrain future research, but the data do
not justify production sensory weights. A next evidence round should collect
or lawfully acquire sensory outcomes across multiple preparation families,
multiple roast categories, replicated crossed cells, and meaningful milk
coverage. Source, country, coffee, panel, and repeated-measures structure must
be retained so any later mixed or resampled analysis can model dependence.

An independent ordinary-user label study should precede UI finalization. It
should test family-choice comprehension, especially AeroPress/hybrid wording,
stovetop/boiled wording, espresso + water, and milk-coffee distinctions, in
both target languages. The seven roast positions remain fixed as the product
minimum while lexical mappings may be refined or left unresolved.

Embeddings remain deferred. If deterministic lexical coverage is later shown
to be inadequate on an independent benchmark, an embedding baseline may be
compared using the same frozen split and abstention-aware metrics. No pgvector
dependency or Q1–Q5 ranking work belongs to this round.
