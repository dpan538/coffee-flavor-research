# Model-prebuild leakage audit

Every future-eligible partition has declared grouping keys and a leakage
check. Future splits must keep connected observations from the same source
family and protected coffee, participant, document, genotype/harvest,
preparation, roast, or milk grouping on one side of a split as applicable.

No random row-level split is approved. The current audit confirms metadata
completeness and forbidden joins only; because no model or evaluation ran, it
does not report predictive performance.
