# Sensory data coverage

The governed inventory now has nine independent coffee-sensory source
families and four method families. It contains 4,344 source-local observation
rows, 230 sample/configuration identities, and 520 disclosed participants or
panelists. Five families include ordinary users and four include trained or
reference panels.

Scores remain source-local. RATA, CATA, hedonic liking, Q-grader profiles, and
descriptive intensity are not converted into a common response scale. Counts
describe coverage, not pooled sample size or generalizability.
