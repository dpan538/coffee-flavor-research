# Data harmonization status

Harmonization is exact only where source meaning and coding permit it. Seven
features are semantically compatible, seven are partially compatible, three
are `NOT_COMPATIBLE`, and three are `SOURCE_LOCAL_ONLY`. Roast schemes,
descriptor presence, basic tastes, body, astringency, industry expressions,
and relationship memberships remain partial.

Missing means unreported, unavailable, structurally inapplicable, or excluded
according to the feature definition; it never means zero. All future joins
must retain source and partition identity.
