# Global flavor corpus results

Round 3J is a partial global scale-up. The continuation admits three new
independent source families, six flavor-description documents, 37 exact
source-authored expression occurrences, and 27 genuinely new normalized expressions,
six source-local sensory configurations, and nine coffee/product identities.

| Metric                                       | Baseline plus admitted delta |
| -------------------------------------------- | ---------------------------: |
| Governed unique normalized expressions       |                        3,023 |
| Admitted flavor documents                    |                        4,143 |
| Admitted flavor-expression occurrences       |                       12,792 |
| Source-local sensory samples/configurations  |                          236 |
| Coffee sensory source families               |                           12 |
| Lexical training-eligible unique expressions |                          700 |
| Source classes with admitted data            |                            5 |

The document and occurrence totals use the full frozen v0.1.0 language corpus,
not only the narrower 3,289 contemporary-document baseline. The new admissions
do not mutate that release. Raw volume, admitted observations, unique
identities, and effective units remain separate in
`db/data/round3j/global-corpus/GLOBAL_FLAVOR_CORPUS_METRIC.tsv`.

The 10,000-document, 40,000-occurrence, 6,000-unique-expression,
5,000-training-expression, 500-effective-sample, and six-admitted-class gates
do not pass. No model training or official training-corpus freeze follows.
