# Expanded public dataset design

## Planned scale

```text
green coffee lots: 24
roast batches: 168
preparation families: 8
roast categories: 7
beverage samples: approximately 3,456 at three replicates
reference assessors: 40
ordinary users: 800
sessions: staged across sites and cohorts
estimated collection: 9-18 months
```

The expanded design adds stovetop/boiled, broader cold and milk conditions,
all roast categories, multiple lots per origin/process stratum, bilingual
participants, and independent sites. It supports stronger lot-level external
testing, subgroup reliability, milk-mode comparison, and later ML benchmarks.

The count is a planning envelope, not a power claim. Each staged release must
use simulation based on earlier variance, item exposure, clustering, dropout,
and desired interval width before final enrollment. Major costs are controlled
roasting, multi-family equipment, physical preparation, participants,
bilingual administration, measurement, cross-site QA, and archival release.
