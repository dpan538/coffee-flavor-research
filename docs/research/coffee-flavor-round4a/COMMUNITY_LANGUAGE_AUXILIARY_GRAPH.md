# Community-language auxiliary graph

`G_community` is a distinct auxiliary layer for ordinary-language variants,
phrase retrieval, query expansion, hard negatives, semantic embeddings, and
professional-to-consumer explanation. It cannot independently create P1/P2
evidence, competition observations, professional co-assertion edges, or
ontology promotion.

Round 4A contains zero admitted community-language edges. Existing language
documents remain reference corpora until source-specific rights and a governed
edge-construction protocol exist. The deterministic engine accepts only typed
`COMMUNITY_LANGUAGE_EDGE` inputs and caps their contribution.
