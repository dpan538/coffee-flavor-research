# Project review protocol

`PROJECT_REVIEWED_PROVISIONAL` is separate from professional and expert review.
A trained project member or independent annotator may verify source-text
identity, segmentation, obvious spelling/plural normalization, canonical
candidate mapping, duplicate/publication-layer disposition, and task relevance.

The decision surface includes `ABSTAIN`, `UNRESOLVED`, `MULTI_TARGET`, and
optional expert escalation. Project review cannot claim professional judging,
expert cupping authority, objective flavor truth, or external validation. It
does not increment the strict migration 058/059 professional-reviewed gate.

Only a row with task-specific rights may enter a project experiment manifest.
The current manifest is intentionally empty.
