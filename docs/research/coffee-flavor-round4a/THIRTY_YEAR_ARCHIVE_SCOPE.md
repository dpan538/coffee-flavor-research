# Thirty-year archive scope

The fixed primary window is 1996–2025. For a later series, the project uses the
series scope start recorded in the expectation ledger. The 2026 rows are
separate `CURRENT_YEAR_INCOMPLETE` supplements and never enter the primary
denominator.

The current denominator is 389 series-years across 23 competition series. All
389 have terminal classifications: 3 descriptor-bearing, 150 ranking-only, 47
metadata-only, 188 not found, and 1 access blocked. Terminal classification is
100%; acquired-payload coverage is only 200/389 (51.41%).

Several later-series starts are explicitly marked provisional. Freezing the
Round 4A denominator makes current progress reproducible; it does not turn a
provisional inception year into historical fact. Edition-level verification is
the next archive task.
