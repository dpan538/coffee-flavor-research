# Conditional classical baseline decision

The rollback-only pipeline smoke checks feature input, coffee/source grouping,
training and inference APIs, temporary serialization, metric output, a model
card, and restricted-locator exclusion. It uses three explicitly synthetic
rows in a temporary directory and persists no weights or training rows.

No empirical classical baseline ran. Model-use basis, label review, independent
family count, normalized-label support, ambiguity challenge scale, and grouped
holdout gates all fail. A deterministic retrieval/ranking baseline is valid as
software behavior, not empirical model performance.

`EMPIRICAL_MODEL=false`, `PERFORMANCE_CLAIM_ALLOWED=false`, and
`MODEL_WEIGHT_RELEASE_ALLOWED=false`.
