# Context data source matrix

## Rights policy

Bibliographic access is not reuse permission. Article and standards metadata are stored under a metadata-only policy with `production_export_allowed=false`. No protected definitions, tables, or article text are seeded.

Dryad states that its published datasets use CC0 and explains that source material it cannot publish is excluded from the repository ([Dryad licensing](https://datadryad.org/stash/our_platform#licensing)). Round 3A records three Dryad datasets as rights-cleared candidates. It does not import their raw files or claim that the associated journal article is CC0.

## Excluded or deferred sources

- Commercial roaster pages: not acquired; public visibility was not treated as reuse permission.
- Proprietary standards/member-only material: metadata may identify it, but protected content is not stored.
- A non-commercial electrochemical dataset found during discovery: deferred because CC BY-NC does not satisfy production commercial-use needs.
- General coffee-review datasets without explicit preparation/roast protocol: insufficient for context-effect estimation.

## Import gate for a later round

Before importing a candidate dataset, verify the repository landing page, exact version, file hashes, row counts, codebook, missing-value semantics, licence at that version, personal-data risk, and compatibility with the observation-context schema. Record raw-file redistribution separately from derived-result redistribution.
