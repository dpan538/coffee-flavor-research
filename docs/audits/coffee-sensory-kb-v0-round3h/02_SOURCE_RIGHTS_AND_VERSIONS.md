# Source rights and versions

Eight newly governed sources have independent-family, canonical-origin,
version, license, rights, privacy, snapshot, and export decisions. The five
outcome sources are CC BY 4.0. Condelli, Heo, and Coffee Cuality contribute
published instrument metadata and evidence constructs under source-specific
reuse decisions; they do not create sensory outcome rows.

Ten logical derived files and eight source snapshots are hash-governed. Only
public aggregates or identifier-free data are present. Request-only raw rows
and any confidential participant data are excluded.
