- Final local/remote SHA and clean-worktree state are self-referential or
  post-commit facts, so the final task response reports their observed values.
- Remote CI cannot be known by the commit it validates; the final task response
  reports the final run URL and result.
- Zero affirmative counts do not mean a purpose is forbidden: conditional,
  pending, unknown, prohibited, and owner-policy-required states remain
  separate in the purpose-specific matrix.
- No human precision, recall, agreement, or semantic error metric is reported
  because the 900-row blind audit template contains no completed human review.
- No training/evaluation split metric is reported because only deterministic
  feasibility buckets were created and no model run was authorized.
