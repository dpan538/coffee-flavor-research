# Protocol validation

The minimum design reconciles to:

```text
COFFEE_LOT_COUNT=2
ROAST_BATCH_COUNT=14
PREPARATION_FAMILY_COUNT=7
ROAST_CATEGORY_COUNT=7
CONDITION_CELL_COUNT=66
BEVERAGE_REPLICATES_PER_CELL=2
BEVERAGE_SAMPLE_COUNT=132
REFERENCE_ASSESSOR_COUNT=12
REFERENCE_PRESENTATION_COUNT=792
ORDINARY_USER_COUNT=60
ORDINARY_USER_PRESENTATION_COUNT=720
MILK_MODE_INCLUDED=true
CALIBRATION_POWER_STATUS=FEASIBILITY_ONLY
```

The preferred and expanded scales are separately costed. The protocol covers
material identity, recipes, replication, blinding, serving control,
randomization, deviations, two observation cohorts, milk pairing, bilingual
question capture, grouped splits, analysis baselines, metrics, and release
governance. Two lots cannot support a defensible development/validation/test
lot split, so performance remains `NOT_ESTIMABLE` at the minimum scale.
