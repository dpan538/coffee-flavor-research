# Source and dataset audit

The final search reviewed ten named candidates across Dryad, Mendeley Data,
publisher supplements, an institutional repository, GitHub, and a public taste
test. File-level hashes were recorded where bytes were downloaded. Three
resources have reusable rights for limited machine use, but none contains the
required combination of comparable coffee, multiple preparation conditions,
seven-level or sufficiently resolved roast variation, sensory outcomes,
ordinary-user question responses, replication, and clean release rights.
