# Research questions

Each question is `NOT_YET_TESTED` unless a later traceable finding updates its
state.

## Language and comprehension

1. How do ordinary users currently describe coffee?
2. Which professional descriptors are unfamiliar, confusing, overly literal,
   or culturally/translation sensitive?
3. Which broad everyday terms help users reach a more specific reference?
4. Which differences arise between package language and user perception?

## Interaction burden and suggestion

5. Can a low-burden sequence improve specificity without creating suggestion
   bias?
6. How many questions are acceptable in a café or home-brew context?
7. Do users understand the difference between five primary and three secondary
   candidates?
8. How often do users prefer abstention or “none of these”?

## Context semantics

9. How much does preparation (C0) contribute to a useful reference set?
10. How much does roast (C1) contribute, and how confident are users in choosing
    a roast category?
11. When should explicit sensory answers override context priors?
12. Does asking for context first create expectation bias?

## Outcome and trust

13. Does the result help comparison, vocabulary learning, or memory?
14. Does the interface increase confidence appropriately, or create false
    certainty?
15. Which explanations make uncertainty, evidence role, and package-note
    disagreement understandable?
16. Which trust concerns or privacy concerns arise?

## Future adaptive-policy questions

17. Which question produces the most useful reduction in candidate ambiguity?
18. When should the system stop rather than ask another question?
19. Does an exceptional fifth question add value commensurate with its burden?
20. Which user-selected references become valid behavioral relevance evidence,
    without being mislabeled as professional sensory truth?

Answers require consented fieldwork or appropriately rights-reviewed language
analysis. Product design choices alone do not answer these questions.
